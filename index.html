RXF — eXtreme Flash Format

Modern, lightweight binary format for 2D animation and interactive content. No plugins. Just pure web.

Get Started Open Editor GitHub

Why RXF?

Lightweight Binary

Compact format with streaming support. Smaller than JSON, faster than XML.

No Plugins

Runs on Canvas API. Works everywhere — Chrome, Firefox, Safari, Edge.

XFC Language

Simple scripting with variables, events, and drawing API.

Easy Embed

One line of HTML. One script tag. Works instantly.

Quick Start

1. Embed Player

<script src="https://cdn.jsdelivr.net/gh/xrxf/xrxf/player.js"></script>
<div data-rxf="animation.rxf" width="800" height="600"></div>

2. Write XFC

var x = 0
var y = 100

on frame each {
    x = x + 2
}

draw.fillStyle("#ff0000")
draw.fillRect(x, y, 50, 50)

Features

Vector drawing Sprite import Sound support Frame-by-frame Console debug Binary format Streaming Responsive Open source

RXF Binary Format

[HEADER] 24 bytes
  - Magic: "RXF\0"
  - Version (major/minor)
  - Scene count

[SCENE]
  - Scene header (duration, layers)
  - Tag stream (SET_BG, DEF_SPRITE, PLACE, MOVE, DRAW, SCRIPT)

[FOOTER]
  - Metadata, signature
